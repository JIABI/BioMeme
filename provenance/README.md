# Provenance

The scientific implementation comes from the published BioMeme archive, DOI [10.5281/zenodo.24008759](https://doi.org/10.5281/zenodo.24008759), file `BioMeme_4_22_software.zip`, under `BioMeme_4_22/software/BioMeme/`.

`SCIENTIFIC_SOURCE_MAP.json` records the original archive member and SHA-256 for copied files, their current hash, and whether the GitHub packaging changed them. Numerical modules and reproduction entry points remain byte-for-byte identical to that archive. Documentation and the installation/data-fetch wrapper are adapted for a standalone repository.

The root `SOURCE_FUNCTIONS.json` is the original scientific function map. Its `/ARCHIVE/...` strings identify historical sources; they are provenance labels, not local paths required to execute this repository. Those labels are preserved rather than rewriting registered history.

`RELEASE_VALIDATION.json` records the actual validation of this GitHub package. Historical software receipts remain in the Zenodo archive and are not presented as tests of this release.
