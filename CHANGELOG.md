# Changelog

## 4.22 — 6 November 2026

Prepared the public GitHub repository from the published [BioMeme 4.22 collection](https://doi.org/10.5281/zenodo.24008759).

- Kept the scientific implementation, model grids, seeds, numerical definitions and original tests from software version 4.21.
- Retained the complete U2OS four-fold example, the prepared-data memory interface and the original statistical replay code.
- Added checksum-verified retrieval of the example and statistics inputs from the fixed Zenodo archive.
- Kept large data, historical records and the full-study inspection archive on Zenodo.
- Added public installation instructions, citation metadata, scope documentation and lightweight test automation.

This is a repository-packaging release. It introduces no new scientific analysis or fitted-model result. The runnable commands and the complete study archive have different scopes, documented in the README.
